# calc-bot (@PrideStatistic_bot)

Отдельный процесс, свой Railway service, свой volume — не пересекается с workchat-bot.

## Railway setup

1. **New Service** в проекте (или отдельный проект):
   - **Root**: этот же репо `workchat-bot`
   - **Start command**: `python -m calc.main`
   - **ENV**:
     ```
     CALC_BOT_TOKEN=8650100450:AAFP_nSpfUIrd_Ckoa-DexUqlAMJslq-QbQ
     CALC_OWNER_IDS=467916027        # tg_id SIMBA (можно через запятую)
     CALC_DATA_DIR=/data-calc
     ```
   - **Volume**: mount `/data-calc` (Persistent) — там будет `calc_state.json`

## Первый запуск

1. Написать боту `/start` в личку — проверить что жив.
2. Owner добавляет бота в **админ-чат** (группа), пишет `/админнастройка` → чат назначен админским.
3. Owner добавляет бота в **клиентский чат** (группа партнёра), пишет `+партнёр @nickname` → чат зарегистрирован.
4. В админ-чате:
   - `/курс <chat_id> 80` — установить курс rub→usd
   - `/напр <chat_id> О1 20` — направление О1 с комиссией 20%
5. В клиентском чате партнёр:
   - `/начатьдень`
   - `+100к О1` — добавить 100 000 руб по О1
   - `/стата` — увидеть панель
   - `/выплата` — запросить выплату

## Команды

**Owner/admin (в админ-чате или DM owner):**
- `/админнастройка` — назначить админ-чат (в группе)
- `/курс <chat_id> <число>` — курс rub→usd
- `/напр <chat_id> <имя> <%>` — добавить/обновить направление
- `/напр_вкл <chat_id> <имя>` · `/напр_выкл` · `/напр_удал`
- `/чаты` — список клиентских чатов
- `/рассылка <текст>` — во все клиентские чаты

**Партнёр (в своём клиентском чате):**
- `/начатьдень`
- `+100к О1` (или `+100000 О1`, `+1.5м О2`) — добавить сумму
- `/стата` — статистика
- `/статус` — направления + запросить реквизит
- `/выплата` — запрос выплаты
- `/профиль` — партнёрский кабинет + работники
- `/настройка` — направления + TRC20 адрес
- `/напр О1 20`, `/напр_вкл О1` (короткий синтаксис в своём чате)
- `/курс 80` (короткий синтаксис)

## Работники

Партнёр → `/профиль` → **👥 Мои работники** → **➕ Добавить работника**.
Работник должен быть админом чата (или напиши что-нибудь и повтори).
Разрешения (галочки): устанавливать адрес / добавлять направления / запрашивать выплату.

## Auto-cleanup

Промежуточные сообщения (`+100к О1` + ответ бота `✅ +100 000₽`) удаляются через 20 сек.
Остаются: команды пользователя (/стата и т.д.), карточки заявок, ответы админа.

## Storage

`/data-calc/calc_state.json` — atomic write через `_lock`. Один файл, простой backup копированием.
